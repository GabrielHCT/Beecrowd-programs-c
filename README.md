# Beecrowd Programs – C

This repository contains solutions to programming problems from **Beecrowd (formerly URI Online Judge)**, implemented in the **C programming language**.

## 📌 About
The programs were developed following Beecrowd’s problem statements and constraints, with a focus on:
- Logical reasoning
- Algorithm implementation
- Efficient use of the C language
- Competitive programming fundamentals

## 🛠 Technologies
- C (ANSI C)
- Standard C Libraries

## 📂 Repository Structure
Each file corresponds to a specific Beecrowd problem and is named according to the problem or its identifier.

## 🎯 Purpose
This repository was created for **learning, practice, and algorithmic improvement**, reinforcing problem-solving skills and foundational programming concepts.

## 📎 Platform
Problems available at: **beecrowd.com.br**

Feel free to explore, study, and contribute!
